# Красный щит: спасти напарника

Одиночная браузерная игра по рисунку пользователя. Три миссии: спасти ковбоя в форте, пройти лабиринт Хранителя и победить Стража в Тёмном лесу.

[Играть в браузере](https://red-shield-rescue.nik-houston.chatgpt.site)

## Открыть проект в Cursor

1. В Cursor выбери `Clone Repository` и укажи `https://github.com/Houston-nik/red-shield-rescue.git`.
2. Открой папку проекта и встроенный терминал.
3. Запусти `python3 -m http.server 8080 --directory dist`. В Windows можно использовать `py -m http.server 8080 --directory dist`.
4. Открой `http://localhost:8080` в браузере. Python 3 должен быть установлен.

Игра не требует установки npm-пакетов или ключей API. Файлы в `dist` являются исходниками, их можно редактировать напрямую.

## Миссии

1. **Форт.** Освободи ковбоя и вернитесь к воротам вместе.
2. **Лабиринт Хранителя.** Ковбой ждёт у входа. Найди Хранителя, выбери один из трёх обликов. По дороге аптечки, воины зла, рогатые твари и две скрытые пасхалки, которые усиливают оружие.
3. **Тёмный лес.** Перед входом откроется **Гардероб**: надень любой найденный облик и иди к Стражу леса. Это главный босс.

Как бить босса:

- На спине у Стража вязанка дров — это броня. Пока она цела, обычные удары почти не проходят.
- Страж бьёт по-разному: замахивается вязанкой, кидает брёвна, поднимает корни и разбегается.
- **Щит** ловит брёвна. От корней нужно отойти. От замаха — шаг в сторону или щит.
- После каждого удара броня на миг открывается. Вот тогда бей.
- Когда здоровья половина, вязанка трескается. Страж злится и быстрее, но все удары уже проходят.
- За победу в гардероб кладётся **Кора стража**.

Облики:

- **Лиловый страж** — щит держится дольше.
- **Огненный клинок** — удар тяжелее.
- **Пьетон** — копьё достаёт дальше, раны медленно затягиваются.

Выбор один на прохождение. Новую попытку лабиринта можно начать и выбрать иначе. Найденное лежит в **Гардеробе** на стартовом экране: Маг, выбранный облик и пасхалки. Надетый облик работает в следующей миссии.

## Управление

WASD / стрелки: движение. Мышь / F: атака. Пробел: направленный щит. E / контекстная кнопка: освобождение или разговор с Хранителем. Esc / P: пауза. ♪: музыка и звуки. На сенсорном экране: джойстик и кнопки.

## Устройство

Статическая страница, Canvas 2D и ES-модули. Зависимости и внешние API для игры не требуются.

- `dist/engine.js`: симуляция, коллизии, поиск пути, бой, NPC, исход миссии.
- `dist/levels.js`: карта форта, генерация лабиринта, облики и пасхалки.
- `dist/game.js`: меню, HUD, пауза, гардероб, победа и поражение.
- `dist/wardrobe.js`: гардероб — Маг, выбранные облики и найденные пасхалки запоминаются.
- `dist/music.js`: свой напрягающий фон в духе survival horror — редкое пианино, смена аккордов, при атаке врага резкий ужас на полную. Не саундтрек Resident Evil, а оригинальная музыка.
- `dist/style.css`: адаптивный интерфейс.
- `dist/assets/characters.png`: герои форта по рисунку пользователя.
- `dist/assets/hermit.png`, `skin-*.png`, `beast.png`, `warden.png`: Хранитель, облики, тварь и Страж леса.

Необходим HTTP-сервер для ES-модулей. Для локального запуска: `python3 -m http.server 8080 --directory dist`. Опубликованная версия запускается по ссылке.

Публикация: статические файлы из `dist`, идентификатор проекта хранится в `.openai/hosting.json`.

## Как устроены ощущения (Октализ)

Коротко: в лабиринте специально смешаны 8 «кнопок интереса» из книги Ю-кай Чоу.

1. Смысл — ковбой ждёт, путь ты идёшь один.
2. Прогресс — туман открывается, счётчик тайн 0/2, стрелка к Хранителю.
3. Выбор — три облика играют по-разному.
4. Своё — выбранный облик запоминается.
5. Люди — Хранитель как наставник, ковбой у входа.
6. Редкость — один дар за заход, пасхалки спрятаны.
7. Любопытство — туман, секреты, твари с рывком.
8. Страх потери — можно пасть в коридоре; аптечки спасают.

## Проверка

Синтаксис: `node --check dist/engine.js`, `node --check dist/game.js`, `node --check dist/levels.js`, `node --check dist/music.js` и `node --check dist/wardrobe.js`. Модель отделена от DOM и допускает симуляцию миссии в Node. `window.redShield.status()` возвращает состояние текущей миссии без изменения игры. `window.redShield.wardrobe()` показывает, какие облики и пасхалки уже найдены. Перед Тёмным лесом кнопка открывает гардероб, чтобы выбрать облик.
